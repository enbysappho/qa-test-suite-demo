|---|---|

| Environment | OS, Python version, commit hash |
| Severity | Critical / Major / Minor / Trivial |
| Priority | High / Medium / Low |
| Related test case | TC-xx |

1. ...
2. ...

**Expected result:** ...

**Actual result:** ...

**Evidence:** logs, screenshot, failing test output
